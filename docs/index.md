# Austrian Windatlas library

Welcome. See the top-level [`README.md`](../README.md) for installation
and the quick smoke test. Method modules land one PR at a time; see
`AWA_TRANSITION.md` in the paper repository for the per-file port
plan.

Topics covered as the port progresses:

- `methods.md` — the nine Stage-1 interpolation families and the
  seven Stage-2 extrapolation formulations
- `data.md` — expected `AWA_DATA_ROOT` layout, download recipes for
  TAWES open data, EU-DEM, CORINE, NEWA
- `reproduce.md` — reproducing the paper's Figures 3–5 from a clean
  clone + a one-year subset
- [`amato.md`](amato.md) — status of the licence-blocked Amato family
